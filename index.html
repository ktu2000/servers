개인정보처리방침

본 서비스(Jellyfin 미디어 서버)는 Google Drive를 연결하여 사용자가 자신의 Google Drive에 저장된 영상 파일을 스트리밍으로 감상할 수 있도록 합니다.

1. 수집·접근하는 Google 데이터

  • Google 계정의 기본 정보 (이름, 이메일 주소)
  • Google Drive에 저장된 파일 목록 및 파일 내용 (주로 영상 파일)
  • 파일 메타데이터 (파일명, 크기, 수정 날짜 등)

2. 데이터 이용 목적

  • 사용자가 자신의 Google Drive에 있는 영상 파일을 Jellyfin 서버를 통해 스트리밍으로 감상하기 위함
  • Google Drive 파일에 접근하여 재생 가능한 형태로 제공하기 위함

3. 데이터 저장 및 보관

  • Google Drive의 실제 영상 파일은 Google 서버에 그대로 보관되며, 본 서버에 복사하거나 영구 저장하지 않습니다.
  • 재생을 위한 임시 캐시 데이터는 서버에 일시적으로 저장될 수 있으며, 재생이 끝나면 삭제됩니다.
  • 사용자 인증 정보(토큰 등)는 안전하게 저장되며, 서비스 이용 목적 외에는 사용되지 않습니다.

4. 제3자 제공

  • 수집·접근한 Google 데이터를 제3자에게 제공하거나 판매하지 않습니다.
  • Google API를 통해 받은 데이터는 Google API Services User Data Policy를 준수하여 사용합니다.

5. 데이터 삭제

  • 사용자가 Google 계정 연결을 해제하거나 서비스 이용을 중단하면, 저장된 인증 정보와 관련 데이터는 삭제됩니다.
